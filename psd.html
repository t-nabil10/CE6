Polynômes de Second Degré Forme Canonique, Racines et Étude de Signe — 2ème Bac Sciences Économiques

I. Définition et forme développée

Définition : On appelle polynôme de second degré (ou trinôme du second degré) toute fonction de la forme : \[ f(x) = ax^2 + bx + c \quad \text{avec } a \neq 0 \] où \(a\), \(b\) et \(c\) sont des réels appelés coefficients.
Le coefficient \(a\) détermine l'orientation de la parabole : si \(a > 0\), la parabole est tournée vers le haut (∪) ; si \(a < 0\), elle est tournée vers le bas (∩).

II. Forme canonique

Théorème : Tout polynôme de second degré \(f(x) = ax^2 + bx + c\) (\(a \neq 0\)) peut s'écrire sous la forme : \[ f(x) = a(x - \alpha)^2 + \beta \] où : \[ \alpha = -\dfrac{b}{2a} \quad \text{et} \quad \beta = f(\alpha) = c - \dfrac{b^2}{4a} = -\dfrac{\Delta}{4a} \]
\[ f(x) = a\left(x + \dfrac{b}{2a}\right)^2 - \dfrac{\Delta}{4a} \]
La forme canonique met en évidence le sommet de la parabole \(S(\alpha ; \beta)\). C'est le point le plus haut (si \(a < 0\)) ou le plus bas (si \(a > 0\)) de la courbe.

1) Méthode pour obtenir la forme canonique

  1. Calculer \(\alpha = -\dfrac{b}{2a}\).
  2. Calculer \(\beta = f(\alpha)\) (ou \(\beta = -\dfrac{\Delta}{4a}\)).
  3. Écrire \(f(x) = a(x - \alpha)^2 + \beta\).
💡 Astuce : la forme canonique permet aussi de retrouver facilement le maximum ou le minimum de \(f\) : c'est \(\beta\), atteint en \(x = \alpha\).
Exemple 1 : Écrire \(f(x) = x^2 - 4x + 3\) sous forme canonique.
\(a = 1\), \(b = -4\), \(c = 3\). \(\alpha = -\dfrac{b}{2a} = -\dfrac{-4}{2} = 2\). \(\beta = f(2) = 2^2 - 4(2) + 3 = 4 - 8 + 3 = -1\). Donc \(f(x) = (x - 2)^2 - 1\). f(x) = (x − 2)² − 1
Exemple 2 : Écrire \(g(x) = 2x^2 + 4x - 6\) sous forme canonique.
\(a = 2\), \(b = 4\), \(c = -6\). \(\alpha = -\dfrac{b}{2a} = -\dfrac{4}{4} = -1\). \(\beta = g(-1) = 2(1) + 4(-1) - 6 = 2 - 4 - 6 = -8\). Donc \(g(x) = 2(x + 1)^2 - 8\). Vérification : \(2(x+1)^2 - 8 = 2(x^2 + 2x + 1) - 8 = 2x^2 + 4x + 2 - 8 = 2x^2 + 4x - 6\) ✓ g(x) = 2(x + 1)² − 8
Exemple 3 : Écrire \(h(x) = -x^2 + 6x - 5\) sous forme canonique, puis donner le sommet de la parabole.
\(a = -1\), \(b = 6\), \(c = -5\). \(\alpha = -\dfrac{6}{2(-1)} = 3\). \(\beta = h(3) = -9 + 18 - 5 = 4\). Donc \(h(x) = -(x - 3)^2 + 4\). Le sommet de la parabole est \(S(3 ; 4)\), c'est un maximum (car \(a < 0\)). h(x) = −(x − 3)² + 4 · Sommet S(3 ; 4)

2) Sommet et extremum

Propriété : La parabole d'équation \(y = ax^2 + bx + c\) a pour sommet le point : \[ S\left(-\dfrac{b}{2a} ; f\left(-\dfrac{b}{2a}\right)\right) = S(\alpha ; \beta) \]
  • Si \(a > 0\), le sommet est un minimum (la parabole est tournée vers le haut).
  • Si \(a < 0\), le sommet est un maximum (la parabole est tournée vers le bas).
Le sommet \(S(\alpha ; \beta)\) est un minimum si \(a > 0\), un maximum si \(a < 0\).

III. Racines d'un polynôme de second degré

Définition : On appelle racine (ou solution) du polynôme \(f(x) = ax^2 + bx + c\) tout réel \(x\) tel que \(f(x) = 0\).

1) Le discriminant \(\Delta\)

\[ \Delta = b^2 - 4ac \]

2) Les trois cas possibles

DiscriminantNombre de racinesRacines
\(\Delta > 0\) 2 racines distinctes \(x_1 = \dfrac{-b - \sqrt{\Delta}}{2a}\) et \(x_2 = \dfrac{-b + \sqrt{\Delta}}{2a}\)
\(\Delta = 0\) 1 racine double \(x_0 = \dfrac{-b}{2a} = \alpha\)
\(\Delta < 0\) Aucune racine réelle Pas de solution dans \(\mathbb{R}\)
💡 Lien avec la forme canonique : les racines s'obtiennent aussi à partir de la forme canonique : \[ f(x) = 0 \iff a(x - \alpha)^2 + \beta = 0 \iff (x - \alpha)^2 = -\dfrac{\beta}{a} \] Si \(-\dfrac{\beta}{a} \geq 0\), alors \(x = \alpha \pm \sqrt{-\dfrac{\beta}{a}}\).
Exemple 4 : Résoudre \(x^2 - 5x + 6 = 0\).
\(a = 1\), \(b = -5\), \(c = 6\). \(\Delta = (-5)^2 - 4(1)(6) = 25 - 24 = 1\). \(\Delta > 0\), deux racines : \(x_1 = \dfrac{5 - 1}{2} = 2\) et \(x_2 = \dfrac{5 + 1}{2} = 3\). S = {2, 3}
Exemple 5 : Résoudre \(x^2 - 4x + 4 = 0\).
\(a = 1\), \(b = -4\), \(c = 4\). \(\Delta = 16 - 16 = 0\). Racine double : \(x_0 = \dfrac{4}{2} = 2\). On peut factoriser : \(x^2 - 4x + 4 = (x - 2)^2\). S = {2}
Exemple 6 : Résoudre \(2x^2 + x + 3 = 0\).
\(a = 2\), \(b = 1\), \(c = 3\). \(\Delta = 1 - 24 = -23 < 0\). Aucune racine réelle. S = ∅ (pas de solution dans ℝ)

IV. Somme et produit des racines

Propriétés : Si \(\Delta \geq 0\) et si \(x_1\) et \(x_2\) sont les racines de \(ax^2 + bx + c = 0\), alors : \[ x_1 + x_2 = -\dfrac{b}{a} \quad \text{et} \quad x_1 \times x_2 = \dfrac{c}{a} \]
Exemple 7 : Vérifier les racines de \(x^2 - 5x + 6 = 0\) (racines 2 et 3).
\(a = 1\), \(b = -5\), \(c = 6\). Somme : \(-\dfrac{b}{a} = 5\). Or \(2 + 3 = 5\) ✓ Produit : \(\dfrac{c}{a} = 6\). Or \(2 \times 3 = 6\) ✓ Les racines 2 et 3 sont correctes

V. Factorisation d'un polynôme de second degré

Théorème : Soit \(f(x) = ax^2 + bx + c\) avec \(a \neq 0\).
  • Si \(\Delta > 0\) : \(f(x) = a(x - x_1)(x - x_2)\)
  • Si \(\Delta = 0\) : \(f(x) = a(x - x_0)^2\)
  • Si \(\Delta < 0\) : \(f(x)\) ne se factorise pas dans \(\mathbb{R}\)
Exemple 8 : Factoriser \(f(x) = 2x^2 - 7x + 3\).
\(a = 2\), \(b = -7\), \(c = 3\). \(\Delta = 49 - 24 = 25\), \(\sqrt{\Delta} = 5\). \(x_1 = \dfrac{7 - 5}{4} = \dfrac{1}{2}\) et \(x_2 = \dfrac{7 + 5}{4} = 3\). Donc \(f(x) = 2\left(x - \dfrac{1}{2}\right)(x - 3) = (2x - 1)(x - 3)\). f(x) = (2x − 1)(x − 3)

VI. Étude du signe d'un polynôme de second degré

Règle du signe : Soit \(f(x) = ax^2 + bx + c\) avec \(a \neq 0\).
  • Si \(\Delta > 0\) : \(f(x)\) est du signe de \(a\) à l'extérieur des racines, et du signe opposé à \(a\) entre les racines.
  • Si \(\Delta = 0\) : \(f(x)\) est du signe de \(a\) pour tout \(x \neq x_0\), et \(f(x_0) = 0\).
  • Si \(\Delta < 0\) : \(f(x)\) est du signe de \(a\) pour tout \(x \in \mathbb{R}\).
Moyen mnémotechnique : « \(a\) à l'extérieur, \(-a\) à l'intérieur » (lorsque \(\Delta > 0\)).

1) Cas \(\Delta > 0\) (deux racines)

Pour \(\Delta > 0\) : signe de \(a\) à l'extérieur des racines, signe opposé entre les racines (les deux cas \(a>0\) et \(a<0\) sont illustrés).

2) Cas \(\Delta = 0\) (racine double)

Pour \(\Delta = 0\) : signe de \(a\) partout sauf en \(x_0\) où \(f(x_0) = 0\).

3) Cas \(\Delta < 0\) (aucune racine)

Pour \(\Delta < 0\) : signe de \(a\) pour tout \(x \in \mathbb{R}\).
Exemple 9 : Étudier le signe de \(f(x) = x^2 - 5x + 6\).
\(\Delta = 1 > 0\), racines \(x_1 = 2\) et \(x_2 = 3\), et \(a = 1 > 0\). • \(x < 2\) : \(f(x) > 0\) (+) • \(2 < x < 3\) : \(f(x) < 0\) (−) • \(x > 3\) : \(f(x) > 0\) (+) f(x) > 0 sur ]−∞,2[ ∪ ]3,+∞[ · f(x) < 0 sur ]2,3[
Exemple 10 : Étudier le signe de \(g(x) = -2x^2 + 4x - 2\).
\(a = -2\), \(b = 4\), \(c = -2\). \(\Delta = 16 - 16 = 0\), racine double \(x_0 = 1\). Comme \(a = -2 < 0\), \(g(x) \leq 0\) pour tout \(x\), avec \(g(1) = 0\). On peut écrire \(g(x) = -2(x - 1)^2\). g(x) ≤ 0 sur ℝ · g(1) = 0
Exemple 11 : Étudier le signe de \(h(x) = x^2 + x + 1\).
\(a = 1\), \(b = 1\), \(c = 1\). \(\Delta = 1 - 4 = -3 < 0\). Pas de racine réelle. Comme \(a = 1 > 0\), \(h(x) > 0\) pour tout \(x \in \mathbb{R}\). h(x) > 0 sur ℝ

VII. Inéquations du second degré

Méthode : Pour résoudre \(ax^2 + bx + c \geq 0\) (ou \(\leq 0\), \(> 0\), \(< 0\)) :
  1. Calculer \(\Delta\) et les racines éventuelles.
  2. Étudier le signe du trinôme (tableau de signes).
  3. Lire les intervalles solutions selon le signe demandé.
Exemple 12 : Résoudre \(x^2 - 5x + 6 \leq 0\).
Racines : \(x_1 = 2\) et \(x_2 = 3\). Le trinôme est négatif entre les racines : \(f(x) \leq 0\) pour \(x \in [2, 3]\). S = [2, 3]
Exemple 13 : Résoudre \(2x^2 + x + 3 > 0\).
\(\Delta = -23 < 0\) et \(a = 2 > 0\). Donc le trinôme est strictement positif pour tout \(x \in \mathbb{R}\). S = ℝ

VIII. Application économique

Les polynômes du second degré sont utilisés en économie pour :

  • Fonction de coût quadratique : \(C(x) = ax^2 + bx + c\).
  • Fonction de profit : \(B(x) = -ax^2 + bx - c\) (trinôme).
  • Seuilstrong> résoudre \(B(x) = 0\) (racines).
  • Optimisation : le sommet de la parabole donne le maximum ou le minimum (forme canonique).
  • Étude de marché : équilibre offre/demande avec des fonctions quadratiques.
Exemple 14 (application économique) : Le profit d'une entreprise est \(B(x) = -x^2 + 20x - 100\) (en DH).
1) Écrire \(B(x)\) sous forme canonique.
2) En déduire le profit maximal et la quantité qui le réalise.
3) Pour quelles quantités le profit est-il positif ?
1) \(a = -1\), \(b = 20\), \(c = -100\). \(\alpha = -\dfrac{20}{2(-1)} = 10\) et \(\beta = B(10) = -100 + 200 - 100 = 0\). Donc \(B(x) = -(x - 10)^2 + 0 = -(x - 10)^2\). 2) Le sommet est \(S(10 ; 0)\). Comme \(a < 0\), c'est un maximum. Le profit maximal est \(0\) DH, atteint pour \(x = 10\). 3) \(B(x) > 0 \iff -(x - 10)^2 > 0\), impossible car un carré est toujours \(\geq 0\). Le profit n'est jamais strictement positif : il est nul en \(x = 10\) (seuil de rentabilité). B(x) = −(x − 10)² · Profit max = 0 en x = 10

Résumé général

  • Forme développée : \(f(x) = ax^2 + bx + c\) avec \(a \neq 0\).
  • Forme canonique : \(f(x) = a(x - \alpha)^2 + \beta\) avec \(\alpha = -\dfrac{b}{2a}\) et \(\beta = -\dfrac{\Delta}{4a}\).
  • Sommet : \(S(\alpha ; \beta)\) ; minimum si \(a > 0\), maximum si \(a < 0\).
  • Discriminant : \(\Delta = b^2 - 4ac\) détermine le nombre de racines.
  • \(\Delta > 0\) : deux racines \(x_{1,2} = \dfrac{-b \pm \sqrt{\Delta}}{2a}\).
  • \(\Delta = 0\) : une racine double \(x_0 = \dfrac{-b}{2a}\).
  • \(\Delta < 0\) : aucune racine réelle.
  • Somme et produit : \(x_1 + x_2 = -\dfrac{b}{a}\) et \(x_1 \times x_2 = \dfrac{c}{a}\).
  • Factorisation : \(f(x) = a(x - x_1)(x - x_2)\) si \(\Delta > 0\).
  • Signe : \(a\) à l'extérieur, \(-a\) entre les racines (si \(\Delta > 0\)) ; signe de \(a\) partout si \(\Delta \leq 0\).
  • Application économique : seuil de rentabilité, optimisation du profit, coût total quadratique.
💡 Conseils pour le Bac :
  • La forme canonique est indispensable pour trouver le sommet et l'extremum d'une parabole.
  • Commence toujours par calculer \(\Delta\) pour les racines : c'est la clé du chapitre.
  • Vérifie tes racines avec la somme et le produit.
  • Pour le signe, retiens : « \(a\) à l'extérieur, \(-a\) à l'intérieur » (si \(\Delta > 0\)).
  • Si \(\Delta < 0\), le trinôme garde le signe de \(a\) partout.
  • En économie, le seuil de rentabilité correspond aux racines de \(B(x) = 0\), et le profit maximal est au sommet de la parabole (\(x = -\dfrac{b}{2a}\)).
